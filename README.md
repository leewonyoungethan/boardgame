# 안개항 의회

덱 빌딩 기반의 세력 영향력 보드게임입니다. 시작 덱을 점점 강하게 만들면서, 안개 낀 항구 도시의 네 세력과 동맹을 맺고 여덟 구역을 차지하세요.

`index.html` 파일 하나로 되어 있어서, 브라우저로 열면 바로 플레이할 수 있습니다.

## 게임 방법

- 80칸 사각 보드판 위에서 나와 컴퓨터 상대 2명이 10라운드 동안 겨룹니다.
- **뽑기** · 매 턴 덱에서 5장을 뽑습니다. 덱이 비면 버림 더미를 섞어(Fisher–Yates) 새 덱을 만듭니다.
- **주사위** · 주사위 2개를 굴려 배를 움직이고, 멈춘 칸의 효과(금화 상자, 뒷소문, 헌책방, 폭풍, 구역 정박)를 받습니다. 출항을 지나면 금화 +2.
- **카드 내기** · 손패를 작전 테이블로 끌어 놓으면 금화·영향력을 얻습니다. "구역에 놓기" 카드는 지도의 구역 위에 놓습니다.
- **영향력** · 영향력 1 = 큐브 1개. 배에서 6칸 안에 있는 구역에만 놓을 수 있습니다.
- **카드 사기** · 금화로 시장 카드를 사면 버림 더미로 가고, 그 세력 평판이 1 오릅니다.
- **라운드 결산** · 각 구역에서 큐브가 가장 많은 사람(동점이면 없음)이 VP와 세력 평판 +1을 얻습니다. 큐브는 다음 라운드에도 남습니다.
- **동맹** · 한 세력의 평판을 처음 4로 올린 사람이 동맹을 맺고 효과를 받습니다. 다른 사람이 평판을 더 높이면 동맹을 빼앗깁니다. 게임이 끝날 때 동맹 하나당 4VP를 더 받습니다.

## 세력

| 세력 | 동맹 효과 |
| --- | --- |
| 商 상인 조합 | 턴 시작마다 금화 +1 |
| 燈 등불 수도회 | 턴 시작마다 영향력 +1 |
| 埠 부두 노조 | 시장 카드 비용 1 할인 |
| 書 서기원 | 턴 시작 손패 6장 |

## 기술 메모

- 바닐라 HTML/CSS/JS, 라이브러리 없음
- Pointer Events로 만든 드래그 앤 드롭 (마우스·터치), 클릭과 키보드로도 조작 가능
- 컴퓨터 상대는 구역 장악 점수를 시뮬레이션해서 큐브 위치와 구매 카드를 고릅니다
